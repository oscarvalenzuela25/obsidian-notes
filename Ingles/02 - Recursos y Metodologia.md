# 🔗 Recursos y Metodología de Estudio

Este documento centraliza todas las herramientas de tu ecosistema de aprendizaje y explica exactamente cómo y cuándo usar cada una para evitar la sobrecarga de información.

---

## 🧭 Catálogo de Recursos

### 1. Diagnóstico y Medición
- 🌐 **[EF SET (EF Standard English Test)](https://www.efset.org/)**
  - **Función**: Examen oficial y gratuito para certificar tu nivel del MCER (A1 a C2).
  - **Frecuencia**: Realizar el test de 15 o 50 minutos el **Día 1**, y repetirlo cada 2 o 3 meses para medir progreso tangible.

### 2. Fundamentos y Teoría Didáctica (Fase 1 - A1)
- 🌐 **[Pacho Ochoa - Curso de Inglés desde Cero](https://www.pacho8a.com/curso-ingl%C3%A9s-desde-cero/)**
  - **Función**: Tu profesor de base en video. Explica la gramática desde cero en español de manera muy clara y progresiva.
  - **Uso**: Ver 1 video por módulo de teoría, tomar notas de ejemplos y pronunciación.

- 🌐 **[Curso-Inglés.com](https://www.curso-ingles.com/)**
  - **Función**: Enciclopedia gramatical de consulta rápida.
  - **Uso**: Tablas de verbos regulares/irregulares, reglas de plurales y preposiciones cuando tengas una duda puntual.

### 3. Hábitos y Pronunciación
- 📺 **[Video: Adrià Solà Pastor & Charly's Way](https://www.youtube.com/watch?v=XNP6ciUoZNI)**
  - **Función**: Metodología de estudio activo y superación de barreras de pronunciación (sonidos difíciles como la *th*, ritmo de habla).
- 🌐 **[El Eterno Estudiante](https://eleternoestudiante.com/)**
  - **Función**: Técnicas de aprendizaje acelerado (Active Recall y Spaced Repetition).

### 4. Inglés Profesional Tech & Speaking (A2 en adelante)
- 🌐 **[FreeCodeCamp - A2 English for Developers](https://www.freecodecamp.org/learn/a2-english-for-developers/)**
  - **Función**: Ejercicios interactivos con diálogos reales de empresas de software (standups, code reviews, tickets).
  - **Uso**: Comenzar en la **Fase 2 (Nivel A2)** una vez dominados los cimientos de la Fase 1.
- 🎙️ **[Digispeak.io](https://digispeak.io/)**
  - **Función**: Entrenador de conversación con IA para perder el miedo a hablar y pulir la fluidez oral en voz alta.

## ⏱️ Rutina Diaria (30–45 minutos)

El principio fundamental es **alternar días de Input (comprensión) y Output (producción)**:

| Día | Enfoque | Actividad |
| :--- | :--- | :--- |
| **Lunes** | Input (Teoría) | 1 video de Pacho Ochoa + notas breves en Obsidian. |
| **Martes** | Output (Práctica) | Sesión interactiva con Gemini (preguntando: *"¿Qué toca hoy?"*). |
| **Miércoles** | Input (Teoría) | Siguiente lección de gramática / vocabulario. |
| **Jueves** | Output (Práctica) | Ejercicios de escritura y micro-quiz con Gemini. |
| **Viernes** | Fonética / Habla | Repetición en voz alta, deletreo y sonidos clave (Digispeak / Video). |
| **Sábado** | Repaso ligero (15 min) | Revisar [[03 - Diario de Vocabulario y Apuntes]] o roleplay corto. |
| **Domingo** | Descanso | Descanso total para consolidar memoria. |
